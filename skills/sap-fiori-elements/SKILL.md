# SAP Fiori elements

Follow **sap-fiori-boilerplate** for all mandatory bootstrap and Mode B file rules.

Summary only:

- Mode A: `app/gatepass/annotations.cds` + CAP fiori preview
- Mode B: all six files under `app/gatepass/` (see boilerplate)
- Defaults: AppId `gatepass`, service module `gatepass-service`, OData `/odata/v4/gate-pass/`
- Blank UI usually means missing `data-sap-ui-resourceroots` or height CSS
